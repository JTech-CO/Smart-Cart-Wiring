# B1 검증 기록

## 검사한 산출물

모듈형 정적 웹앱, 네 시트의 SVG, A3 가로 PDF 10페이지, EasyEDA Standard JSON, KiCad legacy 보조 회로도, 단자/브레드보드/BOM 데이터입니다. PDF와 웹의 재질 표현은 직접 작성한 비축척 벡터 일러스트입니다. 사진이나 제조사 CAD 치수 도면이 아닙니다.

## 자동 검사 결과

| 검사 | 결과 | 기록 |
|---|---|---|
| 설계 데이터 / 내보낸 회로도 재해석 | 39 / 39 통과 | `tests/design-report.json` |
| 웹 동작 / 문서 / 로컬 HTTP 파일 응답 | 38 / 38 통과 | `tests/browser-report.json` |

정적 검사는 44개 전기 심볼, 194개 단자, 63개 네트, 브레드보드 총 400접점 및 사용 84접점을 대상으로 했습니다. 같은 브레드보드 도체의 네트 충돌, 별도 양극 레일, 저항/점퍼 위치, GPIO 매핑과 출력 파일의 실제 핀·배선·라벨 일치 등을 검사했습니다. 이는 전체 전기회로의 안전 분석 또는 EDA 도구의 ERC와 동일하지 않습니다.

브라우저 검사는 Chromium 144에서 1600×1050 및 390×844 뷰포트로 수행했습니다. 부품 선택, 네트 강조, 실제 포인터 드래그, 휠 확대, 화면 맞춤, 시트 전환, 브레드보드 접점 선택, SVG 다운로드, 독립 HTML에 내장된 PDF/EDA 파일의 바이트 일치 등을 확인했습니다. 모바일 크기의 뷰포트 검사이며 실제 스마트폰 하드웨어 검사나 Safari/Firefox 호환성 검사는 아닙니다.

실행 환경의 관리 정책이 `file://` 및 로컬 HTTP로의 브라우저 페이지 이동을 차단했습니다. 이 정책을 우회하지 않고, 동일한 로컬 HTML/CSS/JS를 `page.set_content`에 넣어 기능을 검사했습니다. 로컬 HTTP 파일 응답은 별도 Python 클라이언트로 검사했습니다. 따라서 브라우저에서 실제 `file://` 또는 HTTP 주소로 이동하는 전 과정을 통과했다고 주장하지 않습니다.

## PDF 육안 검사

최종 PDF 10페이지를 이미지로 렌더링하여 전체 페이지의 구성, 그림 누락, 한국어 출력, 표/본문/푸터 충돌을 확인했습니다. 부록의 본문 영역이 푸터 앞에서 끝나는지도 브라우저에서 측정했습니다. 8페이지 단자표의 마지막 C1 단자를 포함해 총 194단자가 수록되어 있습니다.

## 수행하지 않은 검사

- EasyEDA Pro 실제 가져오기 및 변환 후 ERC.
- KiCad 자체 파일 열기, 변환 및 ERC.
- 제조사 핀·단자 배치와 구매 실물의 대조.
- 배터리/BMS, 모터 스톨 전류, 케이블·커넥터·퓨즈 보호 협조, 컨버터와 USB 허브의 실측 시험.
- 회생 전압, 접촉기 차단, 제동, 조향 기구, 전도·탑승·주행 안전 검증.

별표가 붙은 퓨즈 정격은 확정 구매값이 아닙니다. 브레드보드는 저전류 벤치 검증용이며 주행 진동 환경의 최종 하네스로 사용하지 않습니다. 12V·배터리·모터·서보 전력은 브레드보드로 보내지 않습니다. 파일을 가져오고 배선을 제작하기 전에 실제 부품의 단자·정격과 공급 차단/보호 조건을 검토해야 합니다.
